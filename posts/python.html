Python 装饰器：从入门到实践

2026-09-30 · Python · 7 分钟

装饰器看起来像魔法，其实就一句话：它接收一个函数，返回一个新函数，并把原函数替换掉。Python 里函数是一等公民，这成了可能。

最小装饰器

import functools

def log(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        print(f'call {fn.__name__}')
        return fn(*args, **kwargs)
    return wrapper

@log
def hello():
    print('hi')

hello()

@log 等价于 hello = log(hello)。functools.wraps 保留原函数名和 docstring，调试时不会丢信息。

带参数的装饰器

需要参数时，要再包一层：

def retry(times=3):
    def deco(fn):
        @functools.wraps(fn)
        def wrapper(*a, **k):
            for i in range(times):
                try:
                    return fn(*a, **k)
                except Exception:
                    if i == times - 1:
                        raise
        return wrapper
    return deco

类装饰器

需要状态时，用类实现更清晰：

class Cache:
    def __init__(self, fn):
        self.fn = fn
        self.store = {}
    def __call__(self, *args):
        if args not in self.store:
            self.store[args] = self.fn(*args)
        return self.store[args]

装饰器叠加顺序

多个装饰器自下而上应用，最靠近函数的先执行。理解这一点，@property、@classmethod 叠加就不会写错。

小结

  • 装饰器 = 高阶函数 + 函数替换。
  • 带参数要三层嵌套。
  • 状态用类装饰器管理。
  • 叠加顺序：自下而上。
